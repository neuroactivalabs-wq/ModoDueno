# Modo Dueño — Campaña de contenido

Material de la campaña "Modo Dueño" (Neuroactiva Labs · NeuroBrand).

- `estrategia.md` — estrategia de la campaña
- `calendario.md` / `calendario.csv` — calendario de publicaciones por día
- `guiones-reels.md` — guiones de los reels
- `generador/` — scripts en Python que generan las imágenes (`generar.py`, `datos.py`)
- `imagenes/dia-XX/` — posts, carruseles y portadas de reel por día

El zip con todas las imágenes no se versiona (duplica `imagenes/`).
